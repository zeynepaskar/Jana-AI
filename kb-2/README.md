# База знаний AI Jana (тестовая)

Это учебная база знаний для хакатонного прототипа. Все правила, суммы и сроки условные, контакты демонстрационные. Реальных данных компании здесь нет.

## Состав
- `articles/`: 23 статьи в формате markdown, по одной на файл.
- `tests.md`: набор вопросов для проверки AI Jana.
- `all_articles.md`: все статьи в одном файле (удобно вставить в чат с Claude).

## Формат статьи
В начале каждого файла метаданные:

```
---
id: KB-001
title: Как оформить ежегодный отпуск
roles: [employee, manager, hr]
lang: ru
tags: [отпуск, заявка]
updated: 2026-10-17
---
```

- `id`: уникальный код. AI Jana возвращает его как источник ответа.
- `roles`: кому доступна статья (`employee`, `manager`, `hr`). Статьи, закрытые для роли пользователя, отбрасываются до поиска.
- `tags`: ключевые слова и синонимы, помогают поиску.
- В конце каждой статьи блок «Частые вопросы» с живыми формулировками. Они нужны, чтобы поиск находил статью по обычным словам пользователя.

## Как использовать в проекте
1. Положите файлы в папку проекта (например, `data/kb/`), загружайте их при старте сервера.
2. Перед поиском отфильтруйте статьи по роли вошедшего пользователя.
3. Разбейте статью на фрагменты по заголовкам `##`, ищите по фрагментам, а в источнике показывайте название и `id` статьи.
4. Если лучший фрагмент слабее порога, ответьте «надёжной информации нет» и предложите передать вопрос в HR.

## Два правила для статей
- Один факт живёт в одной статье. Некоторые числа (14 дней, 3 рабочих дня, 15 число, 3 месяца) повторяются в нескольких статьях, поэтому при изменении правьте везде. Значение удобно искать поиском по файлам.
- Статьи для ролей `manager` и `hr` не должны попадать в ответы сотруднику. Проверьте это в тестах.
